# PRD - 個人記帳簿系統

## 1. 專案概述

### 背景與動機
記錄日常開銷是掌握個人財務狀況的第一步。現有的記帳軟體往往功能過於複雜或帶有過多廣告，希望能有一個簡單、直覺且專注於記帳核心功能的個人記帳簿系統，協助自己更有效率地管理個人財務。

### 目標用戶
- 我（個人使用者，需要一個簡單好用的記帳工具）

### 核心價值主張
提供一個極簡、快速操作的個人財務記錄平台，專注於收支記錄與基本財務分析，不帶額外干擾。

---

## 2. 功能需求

以下列出系統的主要功能與對應的使用者故事：

### 1. 紀錄支出
- 作為 **個人使用者**，我希望 **能夠記錄每一筆支出（包含金額、分類、備註等）**，以便 **清楚掌握資金流向**。

### 2. 紀錄收入
- 作為 **個人使用者**，我希望 **能夠記錄每一筆收入（包含金額、分類、備註等）**，以便 **了解整體的資金來源與總額**。

### 3. 可以進行加減乘除 (+-*/) 運算
- 作為 **個人使用者**，我希望 **在輸入金額時可以直接進行加減乘除的簡單運算**，以便 **在遇到多筆小額加總或拆帳時，不需要另外開啟計算機應用程式**。

### 4. 輸入日期
- 作為 **個人使用者**，我希望 **在記錄收支時可以指定日期（預設為今日）**，以便 **補登過去的帳目或預先記錄未來的消費**。

### 5. 分析支出
- 作為 **個人使用者**，我希望 **能夠查看支出的統計與圖表分析（例如按月、按分類統計）**，以便 **檢視自身的消費習慣並進一步優化個人的財務分配**。

---

## 3. 非功能需求

### 技術限制
- 後端框架：Flask
- 前端技術：HTML/CSS (Vanilla CSS) 結合 Jinja2 模板
- 資料庫：SQLite

### 效能與安全考量
- **效能**：系統主要為單人使用，資料量不大，應保證操作反應迅速、頁面載入流暢。
- **資料安全**：提供妥善的 SQLite 資料庫備份機制（或檔案層級保存），確保歷史記帳資料不會輕易遺失。

---

## 4. MVP 範圍 (Minimum Viable Product)

### Must Have (必須有)
- 紀錄支出（包含日期、金額、分類）。
- 紀錄收入（包含日期、金額、分類）。
- 金額輸入欄位支援簡單的四則運算（+-*/）。
- 首頁顯示當月總收入、總支出與結餘。

### Should Have (應該有)
- 支出分析功能（簡單的圓餅圖或長條圖顯示各分類佔比）。
- 基本的歷史紀錄列表，並可以依據月份進行篩選。

### Nice to Have (可以有)
- 收支紀錄的編輯與刪除功能。
- 更多維度的財務報表（年度趨勢圖）。
- 匯出為 CSV 功能。
